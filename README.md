# Palo y Cuchara · Web multipágina

Temporada 2026–2027: Inicio, Orden de mérito Scratch/Hándicap, Calendario, homenaje a campeones anteriores, Galería, Curiosidades y Normas.

## Cómo actualizar

Abre `editar.html` en tu ordenador; pulsa «Guardar» para ver cambios en ese navegador. Después pulsa «Descargar contenido.js» y sube ese archivo a la raíz del repositorio. Los cambios se publicarán al actualizar GitHub Pages. No hay edición remota automática.

Las fotografías originales de algunas curiosidades de Canva aún están pendientes. Sus títulos y el enlace a la web original permanecen en `curiosidades.html`.
